# 📊 Sales Performance Analysis using SQL

##  Project Overview
Analyzed sales data using SQL to uncover key business insights including regional performance, top-selling products, and monthly trends.

## Tech Stack

• SQL (MySQL) 

• DB Fiddle 

• GitHub

## Key Insights: 

• South region generated the highest overall revenue among all regions.  

• Laptop category emerged as the highest revenue-generating product.

• Customer spending analysis identified Rahul as one of the top customers based on total purchases. 

 • Sales showed a steady upward trend from January to March through running total analysis.  
 
• High-value orders were primarily associated with premium electronic products.  

• Comparative analysis helped identify customers spending above average revenue levels.  

• Window Functions enabled ranking of customers based on purchasing behavior.


## Advanced Analysis (Level 2)

• Implemented relational database design using Customers and Orders tables. 

• Used INNER JOIN to combine multiple tables. 

• Calculated customer-wise spending and identified top customers.

• Applied GROUP BY and HAVING for advanced filtering. 

• Simulated real-world business scenarios using relational data. 


## Advanced Analysis (Level 3)

• Implemented Window Functions (RANK, Running Total) for advanced analytics.

• Used Subqueries to solve complex business problems. 

• Identified high-value customers using comparative analysis. 

• Solved interview-level SQL problems such as second-highest sales. 

• Applied analytical thinking to derive business insights from data.
