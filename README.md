📊 Sales Performance Analysis using SQL

📌 Project Overview

This project analyzes sales data using SQL to extract meaningful business insights such as top-performing products, regional performance, and monthly sales trends.

🛠️ Tools Used

- SQL (MySQL)
- DB Fiddle
- GitHub

📂 Dataset Description

The dataset contains:

- Order ID
- Product
- Region
- Sales Amount
- Order Date

🔍 Key Analysis Performed

1. Total Sales

Calculated overall revenue generated.

2. Regional Sales Analysis

Identified which regions contribute the most to revenue.

3. Top-Selling Product

Determined the highest revenue-generating product.

4. Monthly Sales Trend

Analyzed how sales change over time.

5. High-Value Orders

Filtered orders with sales greater than 30,000.

📈 Key Insights

- North region generated strong revenue contribution.
- Laptop is the top-performing product category.
- Sales showed growth from January to March.
- High-value orders are mostly from premium products.
